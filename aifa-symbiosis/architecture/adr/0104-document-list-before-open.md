# ADR-0104. Список документов до открытия отчётного цикла

Статус: принято (24.11.2026, владелец)
Заменяет: —. Уточняет ADR-0103.

## Контекст

При нескольких кандидатах без активного документа планировщику нужен `doc_id` для
первого `aifa_open`. Проверка открытия перед списком блокирует выбор. У старых
распознанных отчётов ещё нет `document.text_pages`.

## Решение

Список и ранжирование `aifa_doc` без `doc_id` доступны до открытия, если в ходе несколько
документов или задан `all_workspace`. Источник списка — зафиксированный набор хода.
Для текста одного документа, `aifa_search` и содержимого артефактов действует прежняя
проверка попытки открытия. Для готового документа без `text_pages` список вычисляет
число страниц по распознанному тексту и сохраняет его для следующих запросов.

## Чем проверяется

C3.6, C3.12 и F13.
